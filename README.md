# Career Civics

Single-player MEP career strategy game. One turn is one month. Habits and Specialisms share Civ-style slots; six-monthly Reviews score Delivery, Technical, Collaboration and Leadership.

## Run locally

```bash
npm install
npm run dev
```

## Play

1. Pick a starter character.
2. Slot Habits / Specialisms (Cards).
3. Spend Hours on the Monthly desk; End month.
4. Every sixth month, take the Review and rebalance your loadout.
5. Pass the gate twice with Growth banked and no Crisis to promote.

Progress saves in `localStorage`. Sample consultancy data — no secrets required.
